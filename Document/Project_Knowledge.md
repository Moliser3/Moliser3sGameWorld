# 项目常识

> 所有助手共享的公共知识

## 项目基本信息
- **项目**：Moliser3sGameWorld（UE5 ARPG 游戏）
- **引擎**：Unreal Engine 5.7
- **语言**：C++
- **项目拥有者**：Moliser3 先生

## 操作方式
- **右键全功能**：移动/注视/攻击全部通过鼠标右键完成
- **左键已废弃**：不再使用
- **右键点击敌人**：近距直接攻击，远距走到攻击距离后自动攻击
- **右键点击地面**：移动

## 技能系统
- **三段式生命周期**：前摇(Windup) → 技能触发(OnExecute) → 后摇(Recovery) → 衔接(Link)
- **技能打断**：后摇阶段全程可被打断，前摇不可打断
- **技能组**：角色在蓝图的 `SkillGroup` 中配置技能，组内循环释放
- **衔接时间**：后摇时间 + 自定义衔接时间，此时间内点击推进索引，超时重置
- **1 技能特例**：技能组只有 1 个技能时，索引永远指向自己（可自打断自循环）
- **所有技能参数蓝图可配置**：前摇/后摇/衔接时间/最大释放技能距离/技能分类 等

## 跳跃技能
- 抛物线位移（非原地起跳），前摇=飞行，后摇=落地收尾
- 读取右键点击的目标位置
- NavMesh 检测目标可达性，不可达则原地起跳
- 碰撞障碍物则落地

## 命名规范
- **所有代码标识符使用英文**：变量名称、方法名称、接口名称、类名、枚举值等所有需要命名的代码标识符一律使用英文
- **所有提示信息使用中文**：注释、备注、描述、蓝图的 DisplayName、日志输出等面向开发者或用户的提示信息使用中文
- 示例：`UPROPERTY(meta = (DisplayName = "最大释放技能距离")) float MaxSkillRange;`

## Git 提交规范
- **提交描述必须使用中文**：所有 `git commit -m` 的描述必须用中文书写，方便项目拥有者 Moliser3 先生阅读
- 示例：`git commit -m "修复: 跳跃技能在连招窗口中的打断逻辑"`
