# 新对话启动流程

> 每次开始新对话时，按此流程操作

## 第一步：发出启动指令

在第一条消息中输入（复制粘贴即可）：

```
阅读项目常识、当前工作状态和技术文档
```

## 第二步：等待回复

CLINE 会依次读取以下文件，然后根据角色信息回复"小C已了解项目状态"或"大C已了解项目状态"：

| 读取顺序 | 文件 | 作用 |
|---------|------|------|
| 1 | 先找 `小C角色信息.md` 或 `大C角色信息.md` | **确定自己的身份** |
| 2 | `项目常识.md` | 了解项目背景、操作方式、技能系统 |
| 3 | `当前工作状态.md` | 了解最新进度、已知问题 |
| 4 | `技术文档.md` | 了解完整架构和系统详解 |

> CLINE 会自动判断：公司电脑上存在 `小C角色信息.md`，家里电脑上存在 `大C角色信息.md`，读到的就是自己的身份。

## 第三步：开始开发

确认 CLINE 已读取完成后，直接提出需求即可。

---

## 小C vs 大C

| 助手 | 位置 | 角色文件 |
|------|------|---------|
| 小C | 公司电脑 | `小C角色信息.md` |
| 大C | 家里电脑 | `大C角色信息.md`（由 Moliser3 自行创建） |

两者共享 `项目常识.md`，项目知识保持一致。

---

## 对话结束时的操作

每次对话结束时，CLINE 会：
1. 更新 `当前工作状态.md`
2. 更新 `技术文档.md`（如有代码改动）
3. 提交并推送 Git
