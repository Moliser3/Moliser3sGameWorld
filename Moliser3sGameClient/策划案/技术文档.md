## 二、类体系

### 2.1 角色体系

| 类名 | 父类 | 作用 | 持有组件 |
|------|------|------|---------|
| `ABaseCharacter` | `ACharacter` | 基础角色，持有通用属性和移动接口 | `UAttributeComponent`, `UDamageCalculatorComponent` |
| `APlayerCharacter` | `ABaseCharacter` | 玩家角色，配置玩家专属移动参数 | `UFacingComponent`, `USkillSystemComponent` |
| `AEnemyCharacter` | `ABaseCharacter` | 敌人角色，配置 AI 移动参数 | （暂无额外组件） |

**ABaseCharacter 关键成员：**
- `MoveToLocation(FVector)` — NavMesh 寻路移动
- `StopMovement()` — 停止移动
- `GetSpeed()` — 当前移动速度
- 速度参数：`WalkSpeed=300`, `RunSpeed=600`, `LockedWalkSpeed=150`, `LockedRunSpeed=300`
- 注视参数：`LockOnRange=1000`, `StopDistance=100`

### 2.2 控制器

| 类名 | 父类 | 作用 |
|------|------|------|
| `AWorldPlayerController` | `APlayerController` | 处理鼠标输入（左键攻击、右键移动） |

**输入映射：**
- 左键（Enhanced Input）→ `OnLeftMouseClick()` → `SkillSystem->ActivateNextSkill()`
- 右键（Enhanced Input）→ `OnRightMouseClick()` → 点击检测 + 移动/注视逻辑

### 2.3 组件体系

| 组件 | 挂载位置 | 作用 |
|------|---------|------|
| `UAttributeComponent` | 角色 | 血量、法力、攻击属性、防御属性管理 |
| `UDamageCalculatorComponent` | 角色 | 计算最终伤害（含暴击、护甲减免） |
| `UFacingComponent` | 玩家角色 | 行走/注视两种朝向模式切换 |
| `UClickDetectionComponent` | PlayerController | 屏幕鼠标射线检测 |
| `USkillSystemComponent` | 角色 | 技能列表管理、技能队列循环、连招窗口 |

## 三、系统详解

### 3.1 技能系统

#### 3.1.1 核心组件

- **`USkillSystemComponent`**：技能系统的核心，挂载在角色上
- **`USkillBase`**：技能基类，所有技能继承此类
- **`UMeleeSlashSkill`**：扇形斩击技能（当前唯一技能类型）

#### 3.1.2 USkillSystemComponent 关键变量

| 变量 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `SkillList` | `TArray<USkillBase*>` | 空 | 编辑器中配置的所有技能 |
| `SkillQueue` | `TArray<USkillBase*>` | 空 | 运行时循环队列，自动从 SkillList 填充 |
| `QueueIndex` | `int32` | 0 | 队列当前索引 |
| `CurrentSkill` | `USkillBase*` | nullptr | 当前正在播放的技能 |
| `CurrentSkillStartTime` | `float` | 0.0 | 当前技能开始时间戳 |
| `bSkillActive` | `bool` | false | 技能是否正在 ACTIVE 状态 |
| `ComboWindowDuration` | `float` | 0.5 | 连招窗口持续时间（秒） |
| `bInComboWindow` | `bool` | false | 是否处于连招缓冲期 |
| `ComboWindowEndTime` | `float` | 0.0 | 连招窗口结束时间戳 |

#### 3.1.3 核心函数

| 函数 | 参数 | 作用 |
|------|------|------|
| `ActivateNextSkill()` | 无 | 按状态机逻辑释放队列中的下一个技能 |
| `AddSkill(NewSkill)` | `USkillBase*` | 添加技能到 SkillList |
| `SetSkillQueue(InQueue)` | `TArray<USkillBase*>` | 设置技能循环队列 |
| `IsSkillActive()` | 无 | 返回是否正在 ACTIVE 或 COMBO_WINDOW 状态 |
| `TickComponent(DeltaTime, ...)` | — | 检查 Duration 到期、连招窗口到期 |

#### 3.1.4 状态机（核心逻辑）

```
            ActivateNextSkill()
                  │
                  ▼
         ┌───────────────────┐
         │    IDLE（空闲）     │ ◀─────────────────────────┐
         └────────┬──────────┘                            │
                  │ 执行技能（QueueIndex 指向的技能）        │
                  ▼                                        │
         ┌───────────────────┐                            │
         │  ACTIVE（播放中）   │                            │
         │  Duration 倒计时    │                            │
         └────────┬──────────┘                            │
                  │ Duration 到期                           │
                  ▼                                        │
         ┌───────────────────┐                            │
         │ COMBO_WINDOW(0.5s)│                            │
         │ 连招缓冲期          │                            │
         └──┬───────────────┘                            │
            │                    │                         │
            │ 0.5s内再次左键      │ 0.5s内没操作            │
            │ ActivateNextSkill  │                         │
            │ → 执行下一个技能    │ → 重置 QueueIndex=0      │
            ▼                    ▼                         │
         ACTIVE               IDLE ────────────────────┘
```

**详细逻辑：**

**`ActivateNextSkill()` 调用时：**
1. 如果 `SkillQueue` 为空且 `SkillList` 有内容 → 自动填充
2. 如果 `bSkillActive == true`（ACTIVE 状态）→ 忽略本次调用
3. 如果 `bInComboWindow == true`（COMBO_WINDOW 状态）→ 执行当前 QueueIndex 指向的技能（不移到下一个），然后回到 ACTIVE
4. 如果两者都 false（IDLE 状态）→ 执行当前 QueueIndex 指向的技能，然后 QueueIndex 移动到下一个位置

**`TickComponent()` 中：**
1. 如果是 ACTIVE 状态 → 检测 `CurrentSkill->Duration` 是否到期
   - 到期后：`bSkillActive = false`，进入 COMBO_WINDOW（`bInComboWindow = true`）
2. 如果是 COMBO_WINDOW 状态 → 检测窗口是否到期
   - 到期后：重置 `QueueIndex = 0`，回到 IDLE

#### 3.1.5 USkillBase 关键属性

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `SkillName` | `FName` | — | 技能名称 |
| `Duration` | `float` | 1.0 | 技能持续时间（秒） |
| `SkillMontage` | `UAnimMontage*` | nullptr | 技能蒙太奇动画 |
| `MontageSlotName` | `FName` | NAME_None | 蒙太奇槽位名称 |

**PlaySkillMontage(Instigator) 流程：**
1. 验证 Instigator 和 SkillMontage
2. 获取 Character → GetMesh() → GetAnimInstance()
3. 调用 `Montage_Stop(0.2f, SkillMontage)` 停止旧蒙太奇
4. 调用 `Montage_Play(SkillMontage, 1.0f)` 播放新蒙太奇

#### 3.1.6 UMeleeSlashSkill 参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `Radius` | 100.0 | 攻击半径（厘米） |
| `HalfAngleDeg` | 22.5 | 扇形半角（度） |
| `BaseDamage` | 5.0 | 技能基础伤害 |
| `MaxZDiff` | 150.0 | 最大高度差 |

**Execute 流程：**
1. 停止移动（`Controller->StopMovement()`）
2. 播放蒙太奇（`PlaySkillMontage(Instigator)`）
3. SphereOverlap 检测附近所有 Pawn
4. 过滤：忽略自身 → 扇形角度过滤 → 高度差过滤
5. 对命中敌人计算伤害（`DamageCalculator->CalculateDamage`）

### 3.2 输入系统

#### 3.2.1 鼠标左键

```
蓝图输入事件（IA_LeftClick Triggered）
  → AWorldPlayerController::OnLeftMouseClick()
    → GetPawn() → GetSkillSystem() → ActivateNextSkill()
```

#### 3.2.2 鼠标右键

```
蓝图输入事件（IA_RightClick Triggered）
  → AWorldPlayerController::OnRightMouseClick()
    → ClickDetectionComponent->DetectMouseClick(false)
    → 命中敌人？ 是 → 移动到停止距离 + 进入注视模式
               否 → MoveToLocation(点击位置)
```

#### 3.2.3 点击检测（UClickDetectionComponent）

- `DetectMouseClick(bDrawDebug)`：从屏幕鼠标位置发出射线，返回 `FClickHitResult`
- 碰撞通道：`ECC_Visibility`
- 检测距离：100000 厘米（1000 米）
- 忽略：玩家自身的 Pawn

### 3.3 朝向系统

#### 3.3.1 两种模式

| 模式 | 说明 | 旋转控制 |
|------|------|---------|
| `Walking` | 面朝移动方向 | 由 CharacterMovement 控制（`bOrientRotationToMovement=true`） |
| `Aiming` | 面朝锁定目标 | 由 FacingComponent 控制（`bOrientRotationToMovement=false`） |

#### 3.3.2 关键函数

- `SetAimTarget(Target)`：设置注视目标，关闭移动朝向
- `ClearAimTarget()`：清除目标，恢复移动朝向
- `GetMovementDirection4()`：获取相对于正面的 4 方向（前/右/后/左），供动画蓝图使用

**Tick 逻辑：**
- 注视模式下，每帧平滑旋转朝向目标（`RInterpTo`，速度 720°/s）
- 距离超过 `LockOnRange`（1000cm）时自动清除目标

### 3.4 属性与伤害系统

#### 3.4.1 属性组件（UAttributeComponent）

| 分类 | 属性 | 默认值 |
|------|------|--------|
| 血量 | MaxHealth / Health | 100 / 100 |
| 法力 | MaxMana / Mana | 50 / 50 |
| 攻击 | BaseDamage / CritRate / CritMultiplier | 50 / 0.3 / 2.0 |
| 防御 | Armor / DamageReduction | 20 / 0.1 |

**事件：**
- `OnHealthChanged(OldHealth, NewHealth)`
- `OnManaChanged(OldMana, NewMana)`

#### 3.4.2 伤害计算组件（UDamageCalculatorComponent）

- `CalculateDamage(TargetAttribute, BaseOverride)` → `FDamageResult`

**计算流程：**
1. `RawDamage` = 自身 BaseDamage（或 BaseOverride）
2. 暴击判定（`CritRate` 概率 → `CritMultiplier` 倍率）
3. 护甲减免：`ArmorReduced = min(Armor, RawDamage * 0.5)`
4. 伤害减免：`FinalDamage = (RawDamage - ArmorReduced) * (1 - DamageReduction)`
5. 返回 `FDamageResult { RawDamage, FinalDamage, bCrit, ArmorReduced }`

## 四、数据流

### 4.1 攻击处理流程

```
玩家按下鼠标左键
  ↓
Enhanced Input → IA_LeftClick → Triggered
  ↓
AWorldPlayerController::OnLeftMouseClick()
  ↓
Pawn → GetSkillSystem() → ActivateNextSkill()
  ↓
USkillSystemComponent::ActivateNextSkill()
  ├─ 状态检查（ACTIVE/COMBO_WINDOW/IDLE）
  ├─ 从 SkillQueue 读取技能
  ├─ 设置 CurrentSkill / bSkillActive / 时间戳
  └─ Skill->Execute(GetOwner())
      ↓
UMeleeSlashSkill::Execute(Instigator)
  ├─ Controller->StopMovement()
  ├─ PlaySkillMontage(Instigator)
  ├─ SphereOverlap 检测敌人
  └─ 对每个符合条件的敌人：
       ├─ DamageCalculator->CalculateDamage(EnemyAttribute, BaseDamage)
       └─ EnemyAttribute->TakeDamage(FinalDamage, Instigator)
           ↓
UAttributeComponent::TakeDamage()
  ├─ Health -= DamageAmount
  ├─ OnHealthChanged.Broadcast()
  └─ 如果 Health <= 0 → 死亡逻辑（待开发）
```

### 4.2 Tick 检测流程

```
USkillSystemComponent::TickComponent(DeltaTime)
  ├─ if (bSkillActive && CurrentSkill)
  │     if (Now - CurrentSkillStartTime >= CurrentSkill->Duration)
  │       → bSkillActive = false
  │       → bInComboWindow = true（进入连招窗口）
  │       → ComboWindowEndTime = Now + ComboWindowDuration
  │
  └─ if (bInComboWindow)
        if (Now >= ComboWindowEndTime)
          → bInComboWindow = false
          → QueueIndex = 0（重置队列）
```

## 五、蓝图配置指引

### 5.1 技能配置

在角色蓝图中：
1. 选中 `SkillSystemComponent`
2. 在 `SkillList` 数组中添加技能实例（`UMeleeSlashSkill` 等）
3. 配置每个技能实例的参数：
   - `SkillName`：技能名称
   - `Duration`：持续时间（与蒙太奇长度匹配）
   - `SkillMontage`：蒙太奇资产
   - `MontageSlotName`：槽位名称（与蒙太奇 Slot Track 一致）
   - `Radius`、`HalfAngleDeg`、`BaseDamage`、`MaxZDiff`：技能参数
4. `ComboWindowDuration`：连招窗口时长（默认 0.5s）

### 5.2 连招机制配置

无需额外配置，行为由 `SkillSystemComponent` 内部状态机自动管理。
